# Applied Energy 论文集投稿：首轮行动清单

## 已知会议要求（待正式通知核对）

- 填写入选论文集信息。
- 会议记录称重复内容不超过50%；须取得正式投稿/专题说明，核实相似度计算口径、豁免内容、引用规则和截止日期。
- 题目和图表需与原期刊发表版本有所区别；不重新计算，优先更换分析呈现和可视化。
- 先提交新的三级框架供审核：标题、摘要、分节标题及子论点。

## 1–2日准备项

- [ ] 获取原期刊最终发表稿、补充材料、原图和可编辑源文件。
- [ ] 获取专题邀请/征稿通知、模板、字数、截止日期及版权/重复发表政策。
- [ ] 建立“原稿—新稿”对应表：保留的研究内容、改写部分、新增解释、拟替换图表及理由。
- [ ] 草拟新题目与摘要逻辑，三级标题逐节写出论点和证据来源。
- [ ] 规划替代图表：先明确要传达的结果和合适编码；不得仅换配色/排版就声称内容不同。
- [ ] 核对每张图是否基于已发表结果；如变更分析或计算，需重新核算并留存方法与数据版本。
- [ ] 审核重复内容政策和版权许可；不保证相似度达标，直到按官方流程核查。

## 框架草稿占位（需源论文后填写）

1. 新标题：待源论文与专题方向确认。
2. 摘要：问题 → 方法 → 主要结果（只填已发表、可复用且获准的结果）→ 贡献。
3. 章节/小节：按原论文科学问题重新组织；每个小节补充一个明确论点和支撑图表。

## 待补材料

原论文题目/DOI、专刊正式要求、投稿截止日期、原图目录、拟保留内容授权状态、目标相似度核查工具/流程。
