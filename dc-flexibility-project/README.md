# 数据中心柔性电力匹配研究工作区

> 项目状态：研究设计与已有数据核查阶段。研究方案依据 2026-10-18 的会议纪要及随附资料建立，2026-10-19 已完成选定前期数据的网盘归档与核验。

2026-10-19 已补充八份本地数据中心研究材料，并建立数据、分析、结果与会议记录目录。见[研究材料索引](sources/local-documents/README.md)及[导入清单](sources/local-documents/import-manifest.json)。方向一的方案简版与配套计算说明均在 2026-10-18 更新；具体研究定义应结合这两份材料阅读。原有启动清单及两项论文任务保留其原有用途。

前期数据包括 NC 全年供需输入、Azure 请求算例、NCC 多年气候计算资料、2023–2025 年需求模拟及周核验样例，已归档到百度网盘 `/科研数据/数据中心研究/20261019`。初始 71 份文件约 22.4 GB，另有研究原文及归档清单。56 份普通数据已删除本地副本，9 份 OneDrive 数据的缓存释放尚未核实，3 份来源说明保留。使用前按[归档清单](data/metadata/baidu-netdisk-archive-20261019.json)下载到相应 `data/raw/` 路径。年份、小时分辨率与复用条件见[既有计算说明](data/metadata/existing-computations.md)；[数据清单](data/metadata/existing-data-inventory.json)为迁移前核查快照，其中本地可访问字段记录核查时状态。本机历史来源映射保存在已忽略的 `data/raw/local-sources.json`。

## 研究目标

从全生命周期视角评估数据中心在 24×7 无碳电力（CFE）转型中，供给侧与需求侧灵活性方案的可行性、成本、环境影响和适用边界。比较正常运营、仅供给侧调节、仅需求侧调节和联合调节，并识别不同气候、减碳目标、技术进步和需求增长下的阶段性方案。

## 工作区结构

- `sources/`：收到的8份源文件，原样归档。`research-report.md` 是数据源核查报告。
- `sources/local-documents/`：八份本地研究原文、阅读索引和文件校验清单。
- `planning/`：任务跟踪、情境定义、数据字典和1–2日启动清单。
- `data/raw/`：只放上游原始数据；尊重来源许可及仓库访问控制。
- `data/interim/`：保留中间处理结果。
- `data/processed/`：分析就绪数据。
- `data/metadata/`：数据来源、许可、字段、转换和校验记录。
- `papers/applied-energy/`、`papers/bird-risk/`：两项论文任务材料及版本。
- `analysis/`、`results/`：脚本/笔记与经核验的输出。
- `meeting-notes/`：决策、假设和会议纪要。

## 当前已知与边界

1. 数据源核查报告认为不存在单一、完整、免费且同时包含建筑几何与深层技术属性的全球数据中心底库；建议分层构库。
2. 报告中的记录数是其核查时点的快照（报告称截至2026-07-27），不得视为当前实时数量或真实全球总量。
3. 全球候选层可评估 PeeringDB、OSM 和 Data Center Watch；区域核验层可评估 PNNL IM3、中国1,005点数据及政府名单；Epoch AI 可补充大型AI项目属性。各来源的粒度、覆盖与许可不同，必须保留来源字段并分层报告。
4. Data Center Watch 含城市质心和跨源重复风险；城市质心不能用于设施周边微气候/暴露分析。OSM/IM3涉及ODbL/DbCL，PeeringDB有AUP限制，商业数据不得擅自下载或再分发。具体许可和研究用途仍需项目负责人复核。
5. 前期选定数据已归档并提供恢复路径；当前研究的负责人、起止日、目标网区、服务边界和参数采用版本仍需按具体任务确认。

## 首1–2日建议顺序

1. 组内确认研究主线、四情境边界、系统边界与任务负责人（见 `planning/day-1-2-kickoff.md`）。
2. 逐项审阅 `planning/four-scenarios.md`，确定供给/需求灵活性定义、基准线、约束和可比指标。
3. 审阅 `planning/data-dictionary-template.csv`，确定数据优先级、空间/时间粒度、字段责任人和许可审查状态；不先做未授权的批量下载。
4. 建立数据来源台账和决策日志；每份新文件登记来源、获取日期、版本、许可、校验和及处理状态。
5. 两项论文按清单收集原稿、投稿/专题要求与已发表版本，先形成待审核的文字框架；不得预设风险结果或相似度达标。
