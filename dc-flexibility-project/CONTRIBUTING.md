# 共同编辑方式

从[任务跟踪表](planning/task-tracker.md)认领一项任务，填写负责人、目标日期和验收材料。修改研究定义时先查看[原始材料索引](sources/local-documents/README.md)和[决策日志](meeting-notes/2026-10-19-step1-decisions.md)。

## 一次修改的流程

1. 在GitHub打开目标文件或在本地取得仓库，先同步最新版本。
2. 团队共同编辑时建议使用独立分支，完成一项清晰任务后提交合并请求，说明改了什么、证据在哪里、哪些尚待确认。
3. 原始研究方案不覆盖修改，修订方案另存版本。未知数据保留为空，实测值、文献值、假设值分开。
4. 原始数据放在本地 `data/raw/`，填写 `data/metadata/` 来源和校验记录；不要把数据文件或本机连接配置提交到公开仓库。
5. 合并后同步任务表；需要导师决策的变化在决策日志保留结论和日期。
