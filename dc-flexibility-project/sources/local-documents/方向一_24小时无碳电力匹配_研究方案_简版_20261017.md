# 数据中心电力柔性与24/7无碳电力转型研究方案

## 科学问题与研究定位

**供能侧柔性、计算需求侧柔性及其协同，能否在保障计算服务的同时降低数据中心向24/7无碳电力转型的全过程成本并支持按期达标；在技术进步与需求增长下，哪些早期投资和运行选择有助于转型，哪些可能造成技术锁定？**

研究分别识别供能侧调节、计算需求侧调节及二者协同的价值，比较其如何改变从当前供电方式逐步走向24/7 CFE的路线。近期影响包括时空错配和供能、储能及计算开支的变化；长期价值取决于这些选择能否支持后续阶段目标，并适应技术进步和计算需求增长。

研究以每个站点、每个有负荷小时100%无碳电力匹配为共同转型终点，并设置不同CFE要求，计算达到各目标所需的成本。比较同一条转型路线时，各运营情境采用相同的阶段目标与最终达标期限。各情境从相同的既有计算设施、供能资产和合同出发，面对相同的计算需求、质量与服务要求、信息和候选建设条件，并沿各自形成的资产和合同继续推进。全过程成本、达标进度和后续调整能力共同决定路径优劣。

借鉴技术锁定研究中的路径依赖概念，本研究将锁定风险界定为：早期投资、合同或基础设施选择留下持久约束，使后续转向严格24/7 CFE需要额外替换、提前退出或面临达标障碍。单独出现未来成本上升或柔性收益下降，尚不足以说明锁定。[技术锁定概念参考](https://doi.org/10.1146/annurev-environ-110615-085934)

重点检验一种可能情形：近期依靠任务转移和电池即可满足阶段目标，因此推迟部分清洁供能建设；后期需求增长、可转移余量减少，而新供能又受建设周期限制，导致补建困难。也可能出现相反结果：柔性持续发挥作用，减少冗余投资并支持按期转型。增加可选控制可以扩大决策空间，锁定判断需要追溯具体投资路径与决策条件。

## 全文核心概念与指标

**柔性净收益是全文的核心经济指标：在相同计算服务、CFE约束、未来情景和评估期下，采用指定柔性权限相对于匹配参照所减少的总经济成本。**全文未加限定的“柔性收益”均指柔性净收益。经济主体为多站点数据中心运营者及纳入其共同决策范围的自持能源资产；成本包括供能、储能、控制实施、任务调整和有依据的业务机会成本。

记同一CFE要求下正常运营成本为 \(C_0\)，采用柔性的成本为 \(C_g\)，则 \(V_g=C_0-C_g\)。正值表示柔性降低成本，零值表示没有净节省，负值表示该实施方案增加成本。比较供能侧已经优化后的需求柔性时，参照改为仅供能侧调节，采用 \(V_{D\mid S}=C_S-C_{SD}\)。每项收益均注明参照、CFE口径、分析层次及评估期；不可行情境不计算成本差额。

| 概念或指标 | 全文采用的含义 |
| --- | --- |
| **电力柔性** | 在设备、合同和计算服务边界内，调整供能安排或计算用电的地点、时间及功率分布的能力；可用权限与实际使用量分别报告 |
| **CFE要求与实际匹配程度** | 前者是预先设定的约束，后者是逐小时核算后得到的结果；全年加权得分与每小时下限分别命名 |
| **柔性净收益** | 同目标、同服务下的总经济成本减少额，主报统一价格年货币/年；多年路线主报共同基年的折现净收益 |
| **单位用电量净收益与成本降低比例** | 分别为净收益除以共同参考用电量、除以同目标参照总成本；各方案使用相同参考用电量，并注明比例分母是否包含共同固定成本 |
| **协同量** | 联合净收益减去两侧独立净收益之和；正值表示互补，负值表示部分替代，零值表示在该对照下可加 |
| **企业参与收益** | 企业实际收入、补偿与现金支出的增量，按合同期或投资寿命评价；与包含机会成本的柔性净收益分别核算 |

电费节约、供能投资变化和实际调节量用于解释净收益来源。CFE目标收紧的额外成本、需求采用阈值、清洁缺口时间结构、储能持续能力、达标与锁定等完整定义见[计算细节中的概念与指标约定](方向一_CFE约束与柔性收益_计算细节_20261018.md#全文概念与指标约定)。

## 情境分组与子情境

### 四类运营情境

| 情境组 | 开放的调节权限 | 子情境安排 |
| --- | --- | --- |
| **正常运营** | 按既定任务派发和供电规程运行，不新增针对小时CFE或电价的主动调节 | 一个共同运营基准 |
| **仅供能侧调节** | 调整供能安排，任务沿用正常派发、排队和执行规则 | 本地供能调节、多站供能协同两种 |
| **仅需求侧调节** | 调整合格计算任务，供能沿用既定规则并保障正常电力平衡 | 地点分配、增加启动时间调整、进一步增加执行过程控制三种 |
| **供需联合调节** | 联合安排供能资源和计算任务 | 两种供能权限与三种需求权限逐一配对，共六种组合 |

### 单侧调节的权限范围

| 调节侧 | 子情境 | 具体范围 |
| --- | --- | --- |
| **供能侧** | 本地供能调节 | 各站在各阶段已投运设备及有效合同权限内，优化本地储能充放电、清洁电力利用和购电安排 |
| **供能侧** | 多站供能协同 | 保留本地调节能力，进一步协调各站供能资源及合同允许分配的清洁份额，遵守地域交付和各站电池边界 |
| **需求侧** | 地点分配 | 允许新请求和尚未启动任务在合格机房间分配，沿用正常队列和执行策略 |
| **需求侧** | 地点与启动时间调整 | 保留地点分配能力，增加真实截止期限内的主动延后启动 |
| **需求侧** | 地点、时间与执行过程调整 | 保留前两种能力，增加经验证的GPU功率调节、检查点暂停恢复及合格运行中迁移 |

调节深度按开放的工具权限界定，任务资格、服务要求和设备能力继续有效。多站供能协同限于实际允许的供电和合同路径；所有涉及任务位置变化的操作均计入需求侧。

上述分组形成十二种运营组合。每一种联合组合均与正常运营及对应的两个单侧情境比较，识别联合调节是否产生额外收益，或者出现替代关系。无法达到共同目标的情境保留为不可行结果，不强行计算成本差额。

### CFE要求与需求侧柔性阈值

CFE达标程度作为约束，成本和柔性收益作为计算结果。拟设置各站全年按电量加权的逐小时CFE目标为90%、95%、99%和100%，并设置无额外CFE目标的参照；这些数值为研究情景。另设每小时最低匹配比例的对照，区分低于100%时允许集中留下缺口与要求每个小时分别达标的差别。严格100%要求各站全部有负荷小时完整匹配。

需求侧分别设置可参与任务份额、最大主动延后时间、跨站承接余量、允许的功率与性能变化，以及恢复迁移成本等阈值。任务资格和真实服务期限构成不可突破的边界；阈值扫描识别不同条件下实际采用多少柔性、收益何时出现或消失。计算细节中的假设参数与实测业务参数分别标明。

供能侧、需求侧及联合调节均计算电费节约、含投资与业务代价的净收益，并识别另一侧已经调节后的额外收益。重点计算供能与储能已充分优化后，需求柔性还能增加多少净价值。企业参与收益按实际收入、付费和补偿权利单独核算。

### 两种经营与转型理念

| 理念 | 决策侧重点 | 需要回答的问题 |
| --- | --- | --- |
| **近期成本导向** | 各阶段满足近期计算服务和CFE要求，优先降低近期运行及新增投入 | 近期节省如何影响后续建设，是否积累补建压力或锁定风险 |
| **转型全过程导向** | 同时考虑后续阶段目标、最终达标期限、建设周期和资产寿命，权衡全过程成本 | 能否在发挥柔性价值的同时，保留后续达标及调整能力 |

每种运营组合均在两种理念下评估。共同阶段目标和终点用于评价所有路线，未按期达标的结果如实列示。两种理念面对相同的信息、预测与未来情景，差别在于决策关注的时间范围及未来约束。

运营比较使用共同的既有资产和合同。转型比较中，各情境可在同一候选集合内选择新增电源、储能、合同及能源设备更新，并承接各自形成的资产与长期承诺；新资源投运后才能用于运营调节。GPU与网络若在未来情景中更新，各运营组合采用相同的外生更新路径。正常运营和仅需求侧情境在新增资产投运后，继续按既定供能规程使用。

## 待检验假说

| 假说 | 可能出现的关系 | 需要检验的限制条件 |
| --- | --- | --- |
| **CFE要求改变柔性的经济价值** | 较宽松的全年汇总目标可允许少量困难小时使用普通购电；接近严格100%后，解决这些缺口的成本进入比较，某些任务调整可能更有价值 | 收益不保证随目标单调增加；供能组合和任务可行性共同决定结果 |
| **缺口的时间结构可能改变工具排序** | 短时、频繁调节可能有利于电池；低频长时缺口若仍可通过延期或跨站承接避开，需求柔性可能节省更多保障成本 | 超过任务期限、缺少补做余量或多个站点同时短缺时，长时储能或可靠清洁供能可能更有效 |
| **供需柔性可能替代，也可能互补** | 任务调整可能减少储能需求；储能也可能将清洁电力送入任务可执行的窗口，使原本受限的任务柔性获得价值 | 通过匹配的单侧和联合对照识别，分别扣除调节及建设成本 |
| **相对优势可能随转型阶段变化** | 供能与储能降价、调度技术进步和计算需求增长可能改变当前的最优组合，早期收益可能持续，也可能消失 | 多年变化与单次缺口持续时间分别分析；锁定需有资产、合同或建设周期等持续约束 |

以上关系均作为待检验假说，允许需求柔性收益很小、没有采用或无法满足目标的结果。具体目标、阈值、收益公式与验证口径见[计算细节](方向一_CFE约束与柔性收益_计算细节_20261018.md)。

### Introduction

交代连续计算需求与清洁供给之间的小时错配，以及走向24/7 CFE需要逐步形成的供能、储能和合同组合。提出研究重点：不同匹配要求下，两侧柔性各有多少净收益，缺口的时间结构是否改变其相对优势，以及近期节省能否转化为支持按期达标的全过程优势。

### Discussion

讨论CFE要求和任务阈值如何改变单侧柔性与供需协同的净价值，以及经营理念如何影响必要投资和后续转型空间；解释长期合同、建设周期和资产寿命带来的持续约束。区分逐小时CFE匹配、实际减排和企业参与收益，说明转型促进或锁定判断的适用条件。

## 拟检验的结论

- **促进转型的条件：**识别哪些单侧权限或联合组合能够在满足计算服务和阶段目标的同时，减少冗余投资、降低全过程成本并保持最终达标能力；联合额外收益的方向由对应对照检验。
- **CFE要求与时间结构的作用：**识别不同匹配要求、任务调整阈值和清洁短缺结构下，两侧柔性的净收益及实际使用量，检验需求柔性、短时电池和长时储能的相对优势是否转变。
- **出现锁定风险的条件：**如果依靠近期柔性节省形成的资产、合同或投资推迟，在未来需求增长和技术变化下造成持续约束，带来额外补建、提前退出或达标障碍，则需要识别相应的技术与投资锁定风险。
- **转型路线的判断标准：**同时考察近期节省、全过程成本、按期达标和面对未来变化的调整能力。研究需要确定哪些投资与运行安排能发挥柔性价值，并保持后续转型空间。

| **经营与收益结算** | 实际租用条款、任务收入及可替代订单净贡献、控制与传输付费、灵活性补偿、费用承担方和收益归属 | 计算两侧净收益及企业实际参与收益，避免重复计入固定租金或电费节约 |
| **未来情景** | GPU能效与性能、执行控制开支、供能及储能成本、有效计算需求与任务结构、计算设施及清洁供能扩展条件 | 研究技术进步与需求增长共同影响下的柔性价值、容量需求及达标风险 |
| **转型路线与资产承接** | 阶段目标与最终期限、已有资产年龄、建设和替换周期、可扩建上限、退役与改造成本 | 识别早期选择的持续影响、后期补建压力和锁定风险 |

任务与运行记录保留原始时间信息，能源数据至少支持小时匹配；各站数据覆盖一致的评估期。
