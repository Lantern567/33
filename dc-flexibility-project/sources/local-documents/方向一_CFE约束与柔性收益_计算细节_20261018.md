# 数据中心CFE约束与供需柔性收益计算细节

本研究在保障相同计算服务的条件下，将CFE要求作为约束，计算供能侧、计算需求侧及联合调节的成本与收益。情境权限采用[研究方案](方向一_24小时无碳电力匹配_研究方案_简版_20261017.md)中的四组十二种运营组合；以下公式对每一组匹配的供能、需求权限分别计算。

## 全文概念与指标约定

### 经济主体与比较参照

本文的经济主体为多站点数据中心运营者及纳入其共同决策范围的自持能源资产。成本按该主体实际面对的设备、合同、电价和业务条件计算。自持资产内部支付在合并口径中抵消，对边界外的供能企业和租户按实际交易记录。电网避免投资、外部减排和社会福利如有评估，作为独立结果列示。

四组参照分别为正常运营 \(0\)、仅供能侧调节 \(S\)、仅需求侧调节 \(D\)和供需联合调节 \(SD\)。每项比较采用相同的CFE约束形式与水平、计算服务、任务和设备条件、外部信息、未来情景及评估期。固定资产运营、能源配置和多年转型分别比较；每一种经营理念内建立对应参照，跨理念成本差另称决策理念的影响。

### 核心指标柔性净收益

**柔性净收益定义为：在相同计算服务和CFE约束下，采用指定柔性权限，相对于匹配参照所减少的总经济成本，包含供能与储能、控制实施、任务调整以及有依据的业务机会成本。**全文未加限定的“柔性收益”均采用此定义。

\[
V_g(q,\theta)=C_0(q,\theta)-C_g(q,\theta).
\]

\(q\)为全年加权CFE目标；逐小时下限分析以 \(\alpha\)替代并另行标明。\(\theta\)为共同的业务、设备和阈值参数。\(C_g\)为指定分析层次和经营理念下的总经济成本；理想优化结果与实际预测执行结果分别标明，不混用参照。

\(V_g>0\)表示减少成本，\(V_g=0\)表示没有净节省，\(V_g<0\)表示该实施方案增加成本。全部相关成本都已进入 \(C_g\)，净收益不再重复扣除调整费用。共同不可行情境不定义货币净收益。

供能侧、需求侧的独立收益是该定义的两种应用。需求柔性在供能已开放条件下的核心增量为 \(V_{D\mid S}=C_S-C_{SD}\)，供能柔性在需求已开放条件下的增量为 \(V_{S\mid D}=C_D-C_{SD}\)。这两项分别回答另一侧已经调节后还剩多少价值。供能侧或需求侧“收益”描述控制权限的贡献，不代表相应设备所有者实际收到的款项。

### 经济指标及单位

| 指标 | 定义 | 单位与解释 |
| --- | --- | --- |
| **总经济成本** \(C_g\) | 同一边界内供能与储能、控制与任务调整、机会成本及共同固定成本之和 | 单年为统一价格年货币/年，多年为共同基年的现值；成本分项见后文 |
| **柔性净收益** \(V_g\) | \(C_0-C_g\) | 全文主指标，主报总额；不同CFE目标各用自身对应的参照 |
| **单位用电量净收益** \(v_g\) | \(V_g/E_{\rm ref}\) | 货币/MWh；\(E_{\rm ref}\)为同批业务按预先固定参考执行策略得到的终端设施用电，各方案及CFE目标使用共同分母 |
| **成本降低比例** \(\eta_g\) | \(V_g/C_0\times100\%\) | 仅在 \(C_0>0\)时报告；主口径包含共同固定成本，若另报排除固定成本的比例须注明分母 |
| **电费毛节约** | 参照与方案实际电费或购电结算之差 | 不含未发生的投资节省；账单范围固定，已进入总成本的节约不再次加到净收益上 |
| **物理耗电变化** | 参照与方案的终端用电及损耗分别作差 | MWh/年；移峰、迁移和功率控制可能改变总耗电，电费下降不要求用电量同比下降 |
| **协同量** \(I\) | \(V_{SD}-V_S-V_D=C_S+C_D-C_0-C_{SD}\) | 货币/评估期；正值表示联合节省超过独立节省之和，负值表示部分替代 |
| **CFE附加成本** \(\Delta C_g^{\rm CFE}(q)\) | \(C_g(q)-C_g(\text{无额外CFE目标})\) | 同一运营组合为满足CFE要求多付出的成本，服务及其他条件保持一致 |
| **CFE要求引起的柔性收益变化** | \(V_g(q)-V_g(\text{无额外CFE目标})\) | 识别匹配要求对柔性净收益的影响；正净收益本身不保证此项为正 |
| **全过程柔性净收益** \(V_g^{\rm PV}\) | \(C_0^{\rm PV}-C_g^{\rm PV}\) | 两条路线采用相同折现率、目标序列与期限，各自承接资产和合同，计入替换、退出与期末残值 |
| **企业增量净现金收益** \(\Delta CF_g\) | 计算收入增量加外部补偿增量，再减实际现金支出增量 | 按企业和合同期核算；多年采用折现净现金增量，机会损失不与同一收入变化重复计入 |

单年总额、单位用电量数值和降低比例配套列示；当成本下降来自很小的相关电费分项时，固定成本分母仍须保持透明。多年单位用电量净收益使用共同参考用电量的折现和作为分母，不以多年现值除以单年电量。各方案实际耗电单列，异质任务的步数、请求数或GPU小时不强行合并为有效工作量。

| **跨站承接余量** | 按站点、时段和GPU型号记录可供新增任务使用的兼容设备，保留显存、互联、网络和服务约束，扣除背景业务及承诺资源；不能仅用平均利用率表示 |
| **清洁保障资源替代量** | 相同目标和服务下，匹配参照与方案所需电源、合同、储能功率或电量容量之差；分别以MW、MWh及合同量报告，负值表示该资源需求增加 |

### CFE与缺口时间结构

| 概念或指标 | 定义及边界 |
| --- | --- |
| **CFE** | 具备明确来源、小时和地域归属、可被本主体合法认领的运行阶段无碳电力；允许的技术范围在情境间一致，生命周期排放另计 |
| **CFE目标与实际得分** | 目标 \(q\)或 \(\alpha\)是输入约束；实际得分 \(Q_s=\sum_tM_{st}/\sum_tL_{st}\)是各站逐小时封顶后的电量加权结果，另报最差小时匹配比例 |
| **严格24/7 CFE** | 每个站点、每个有负荷小时全部终端用电获得合格匹配，同时满足完整声明边界和储能来源约束；年采购等量绿电单独列示 |
| **未匹配电量** | \(U_{st}=L_{st}-M_{st}\)，单位MWh；按站点和小时记录，严格达标时为零 |
| **参考清洁缺口** | 在预先固定的参考任务负荷和清洁供给组合上，新增调节前的不足电量 \(D_{st}^{\rm ref}=\max(0,L_{st}^{\rm ref}-G_{st}^{\rm ref})\)。\(G_{st}^{\rm ref}\)为按参考规程、既有储能及属性规则核算后可交付且可认领的清洁电量，单位MWh；各方案共用同一事件序列 |
| **缺口持续时间与深度** | 同一站点连续正参考缺口构成一次事件，数值容差预先固定；持续时间以小时计，平均及最大功率缺口以MW计，事件缺口电量为期间MWh之和 |
| **缺口频次与恢复条件** | 频次为事件数/年；事件间隔为相邻事件之间的小时数。将SOC和任务积压恢复至规定状态所需的时间、清洁电量与算力另行记录 |
| **跨站缺口重合比例** | 对站点对，双方同时出现参考缺口的小时数除以至少一方出现缺口的小时数；无缺口时不定义。该比例不能单独替代目的站清洁与计算承接能力 |
| **储能持续能力** | \(T_{\rm dis}=E_{\rm usable}/P_{\rm dis}\)，单位小时；\(P_{\rm dis}\)为规定工况下的额定或最大可持续放电功率，\(E_{\rm usable}\)为相同工况下放电端可交付且扣除应急保留的电量，另报效率和充电条件。运行时临时降低功率不改变分类时长；短时与长时以具体持续能力表征，技术类别分别列示 |
| **可达CFE与按期达标** | 给定资产、采购上限、任务和服务约束下可实现的最大共同CFE目标，以及能否在规定阶段与期限满足目标；全年加权目标和逐小时下限分别求取 |
| **技术锁定** | 早期投资或合同通过持续资产、退出费用和建设周期限制后续调整，并造成额外替换、补建或达标障碍；单独收益下降或成本上升不足以构成锁定 |

参考缺口用于比较时间结构，方案运行后的 \(U_{st}\)用于报告实际匹配结果；严格达标不要求参考缺口事件消失。一次事件持续多久与多年投资评价期分别命名。

## CFE目标与成本曲线

设站点为 \(s\)、小时为 \(t\)，\(L_{st}\)为该小时终端设施用电量，单位MWh，包含IT、冷却及配电等用电，不将同一电量的储能内部充电与最终放电重复相加；\(M_{st}\)为具有合格来源、小时和地域归属的匹配电量，满足 \(0\le M_{st}\le L_{st}\)。任务在哪里执行，就在哪里计入用电。各站背景业务、空闲功耗及任务调整产生的用电均纳入负荷。

### 全年汇总的逐小时匹配目标

先逐小时匹配并将匹配量封顶，再要求各站达到全年电量加权目标：

\[
\sum_t M_{st}\ge q\sum_t L_{st}\qquad\forall s.
\]

拟定 \(q\in\{90\%,95\%,99\%,100\%\}\)，另设无额外CFE约束的参照。目标数值为研究情景，不代表现行政策要求。低于100%时，各站允许的未匹配电量上限为 \((1-q)\sum_tL_{st}\)，可以集中在少数小时；不同站点分别核算。

### 每小时最低匹配比例

另设对照，要求每个站点、每个有负荷小时分别满足：

\[
M_{st}\ge\alpha L_{st}\qquad\forall s,t.
\]

采用与全年目标对应的比例，以检验约束形式本身的影响。低于100%时，逐小时下限不能用其他小时的盈余补足；在相同核算边界、匹配量封顶且采用精确值时，两种目标在100%处均要求所有有负荷小时完整匹配。年度采购等量绿电单独列示。

例如，假设某次长时缺口的未匹配电量占全年用电量0.5%，其他时段全部匹配：全年99%目标可以容许该缺口，每小时99%下限则不能容许缺口小时完全使用未匹配电力。此例仅解释约束口径。

储能按站点追踪清洁与其他充电来源、来源时点、损耗及库存，禁止重复认领环境属性。求解时同时施加终端设施用电和包含储能损耗的完整声明边界约束；清洁充电损耗不作为终端匹配量，也不用于扩大未匹配额度。两类约束均满足才判定可行，实际执行后按相同口径检查。各情境使用相同的期初状态及期末库存规则，防止消耗期初库存或留下未完成任务制造收益。

对运营组合 \(g\)及阈值参数 \(\theta\)，计算满足目标的最低成本 \(C_g(q,\theta)\)。报告目标水平、实际CFE得分、最大缺口、用电量和总成本。目标从 \(q_1\)提高到 \(q_2\)的额外成本为 \(C_g(q_2,\theta)-C_g(q_1,\theta)\)；每小时下限对照单独计算。共同目标收紧时，最低成本不下降属于约束关系；成本增加幅度、投资变化和柔性采用量是研究结果。

## 需求侧阈值及共同服务边界

业务与设备给出输入边界，计算求得可行性和经济临界值。输入阈值用于界定任务控制的可用范围，不强制任务接受调整。所有情境完成相同有效工作量、质量和已承诺服务；在线业务尾部时延、任务依赖及硬件兼容性继续约束执行。公开记录缺少的真实服务期限不能从历史完成时刻反推。

| 参数 | 定义及拟定扫描方式 | 数据与约束 |
| --- | --- | --- |
| **可参与任务份额** \(f\) | 按已确认合格的任务数量，分任务类别拟开放0%、25%、50%、75%、100%；同时报告其占全部业务的比例 | 这些比例是研究设定。采用固定且嵌套的任务名单，分别报告任务数、同类参考有效工作量与原策略耗电；100%指全部合格任务 |
| **主动延后上限** \(\tau\) | 拟取0、1、4、12、24小时，识别柔性收益对允许等待时间的变化 | 各任务仍不得超过真实期限；48小时及以上仅在业务有依据时作为业务情景，否则明确列为假设性敏感性分析 |
| **跨站承接余量** \(h\) | 按兼容GPU、显存、互联及背景占用后的实际可用资源计算，扫描数据支持的余量范围 | 目的站原有业务和已承诺任务全部保留；各余量情景内，四组使用相同设施和背景负荷 |
| **执行控制范围** | 选择通过测量验证的功率档位、暂停次数与时长、检查点和迁移方式 | 记录有效速度、整机功率、质量、保存恢复和重算开支；不得假设功率与有效产出同比变化 |
| **调整代价与参与门槛** \(k\) | 以实际费用和可核查业务价值校准，再扫描成本区间；求出实际使用量降至零的临界条件 | 可用货币/次、货币/GPU小时或货币/MWh减少负荷表示，转换时保留原始物理量及成本组成 |

启动延后、完成期限和任务积压分别记录；任务在补做窗口内必须真正完成。完成同等工作所需的实际用电允许变化。GPU时长、暂停时长和迁移量是过程量，不能直接等同于清洁缺口减少量。

租用价格进入实际租期、额外GPU占用和合同付款的计算。共同固定的设备折旧和租金按统一口径计入一次。若已承诺任务按期完成且收入不变，暂停时间不自动对应同额营业收入损失。共同承诺业务必须全部满足；确实挤占这些业务之外的新增可售机会时，给出可售需求和价格依据。缺少这类依据时，单独报告机会成本的敏感性区间。

## 时间结构与待检验假说

单次缺口持续时间和发生频次，与未来多年的技术、需求变化分开分析。在相同CFE目标和服务要求下，比较需求柔性、短时锂电池、长时储能及共同允许的其他清洁供能；长时储能按实际技术的功率成本、电量成本、效率、寿命和建设条件建模。

### 假说一 CFE要求可能提高低频长时调节的价值

较宽松的全年汇总目标可能允许少量困难小时使用普通购电；严格100%则必须解决这些清洁缺口。若任务仍有调整空间，避免的清洁保障成本可能足以支付计算调整代价。检验各目标下需求柔性的实际使用量、净收益和供能容量变化，允许收益没有增加或趋近零的结果。

### 假说二 缺口时间结构可能导致相对优势变化

短时、频繁的缺口可能有利于重复使用电池；低频长时缺口可能需要较大的电池电量容量，若任务可延期或可向其他站点转移，需求柔性可能更经济。超过任务期限、补做余量不足或跨站同时短缺时，需求调整无法覆盖缺口，长时储能或可靠清洁供能可能具有优势。比较时保留普通购电在对应CFE目标下可使用的份额。

记录缺口持续时间、深度、年内频次、事件间恢复时间、未匹配电量、任务可调窗口、补做能力和站点短缺重合程度。缺口识别先在共同资产与正常规程下建立参考序列，再记录各方案形成的剩余缺口；不将优化后已经消失的事件从比较样本中删除。仅比较总能量或同一额定MW，不能代替相同服务与CFE目标下的系统成本比较。

### 假说三 供需柔性可能替代或互补

需求转移可能减少清洁供能或储能容量；储能也可能将清洁电力移入任务有限的执行窗口，使需求柔性成为可用资源。通过对应的四组对照计算协同量，并解释导致替代或互补的具体时段和资源约束。

### 假说四 当前的优势可能随转型进程变化

储能和可靠清洁供能的成本下降，可能改变任务调整的经济性；计算需求增长可能减少GPU补做余量；调度技术进步又可能降低调整代价。沿相同阶段目标比较不同路径的累计成本、建设时序及达标能力。若主张技术锁定，还需追踪早期资产或长期合同、退出费用和建设周期造成的持续约束。

## 供能侧和需求侧收益

### 四组匹配对照

在相同CFE目标、任务阈值、信息、服务和资源条件下，记正常运营、仅供能调节、仅需求调节和联合调节的最低总经济成本分别为 \(C_0,C_S,C_D,C_{SD}\)。每个供能权限等级与每个需求权限等级均建立对应四组。

| 收益指标 | 计算式 | 解释 |
| --- | --- | --- |
| 供能侧独立净收益 | \(V_S=C_0-C_S\) | 常规任务条件下开放供能调节的收益 |
| 需求侧独立净收益 | \(V_D=C_0-C_D\) | 常规供能规程下开放任务调节的收益 |
| 供能已调节后的需求侧增量 | \(V_{D\mid S}=C_S-C_{SD}\) | 重点回答供能侧充分优化后，需求柔性还剩多少价值 |
| 需求已调节后的供能侧增量 | \(V_{S\mid D}=C_D-C_{SD}\) | 任务可调条件下继续开放供能调节的收益 |
| 联合净收益 | \(V_{SD}=C_0-C_{SD}\) | 两侧共同开放后的总节省 |
| 协同量 | \(I=C_S+C_D-C_0-C_{SD}\) | 正值表示联合节省超过独立节省之和，负值表示部分替代 |

独立收益不能直接相加当作联合收益。收益统一报告货币/评估期，并按共同参考策略用电量或同类有效工作量归一化；不同情境的实际耗电另列，避免分母变化造成误读。免费增加可选控制使理想最低成本不增加，是模型性质；实际采用量、净收益大小和临界条件用于检验假说。强制参与、固定启用费用及实际预测误差下的结果分别说明。

### 电费节约与净经济收益

对任一组合 \(g\)，以共同账目分解：

\[
C_g=F+E_g+A_g+O_g.
\]

\(F\)为各情境共同的固定成本；\(E_g\)为供能和储能成本；\(A_g\)为任务及控制产生的额外实际费用；\(O_g\)为有业务依据的计算机会成本。供能和任务控制的实施费用均归入对应成本项。定义：

\[
V_g=(E_0-E_g)-(A_g-A_0)-(O_g-O_0).
\]

分别报告实际电费或购电结算的毛节约、供能与储能总成本节省，以及扣除调整代价后的净收益。

- **供能和储能成本**包括购电、合格清洁采购、基本费用、设备年化或现金投资、运行维护及储能寿命成本；合同结算和售电收益按真实规则计入。
- **任务与控制费用**包括新增租用、额外占用付费、数据传输、控制系统及恢复操作付费；实际耗电统一进入供能成本，不在此重复收费。
- **机会成本**用于尚未纳入逐项收支模型的额外可售机会，以其可核查净贡献计入；净贡献中扣除的电费、租用等可避免费用，不再作为供能或调整费用的减少重复计入。若扩展模型已经显式模拟这些订单的收入与费用，则采用对应利润差，并取消该部分机会成本项。

储能损耗通过充放电和实际购电进入电量与成本，投资、更换和按吞吐计费的退化费用采用一致寿命口径。同一笔PPA结算、储能套利或电费减少只记录一次。

### 企业增量净现金收益

对实际承担费用和获得收益的企业分别核算：

\[
\Delta CF_g=(R_g-R_0)+(P_g-P_0)-(C_g^{\rm cash}-C_0^{\rm cash}).
\]

\(R_g\)为计算业务实际收入，\(P_g\)为灵活性等外部补偿，\(C_g^{\rm cash}\)为该企业承担的现金费用，涉及资本支出时按实际发生时点计入。已通过收入减少体现的机会损失，不再从现金费用重复扣除。按合同期或投资寿命计算折现净现金增量，以非负作为基本参与条件，并另列流动性等约束；首年现金支出增加不能单独判定全期不值得参与。仅同一合并主体内部的支付抵消，对边界外交易按实际收支记录。主指标中的成本节省不自动等于某家企业能够获得的现金收入。

## 资产与转型比较

固定资产运营比较中，四组使用相同GPU、网络、供能设备、储能和合同，仅改变已授权的运行控制。在能源配置比较中，四组从共同候选集合及容量上限选择电源、短时电池、长时储能和合同，GPU及网络条件在同一情景内保持一致；正常组仍使用预先定义的常规运行规程。两类比较分别报告。

多年转型比较继承各自已经形成的资产与合同，新增资源在建设完成后使用。各运营组合采用相同阶段目标、终点期限、折现率、信息和未来情景。全过程成本采用共同折现规则，计入替换、退役和期末残值；单年成本采用一致年化规则，不把年化投资与同一笔现金投资重复相加。

若现有设施下某组无法达到目标，报告不可行、可达匹配程度和限制条件。净收益仅在共同可行范围内计算；新工具使目标从不可行变为可行时，报告其可行性价值及所需费用，不使用任意惩罚值制造收益。

## 文献基础

- [Riepin与Brown：On the means, costs, and system-level impacts of 24/7 carbon-free energy procurement](https://arxiv.org/html/2403.07876)。支持区分匹配要求、清洁供能选择和高目标的成本机制；本文的任务阈值与收益假说需独立检验。
- [Riepin等：Spatio-temporal load shifting for truly clean computing](https://arxiv.org/html/2405.00036v1)。已研究严格CFE下的时空任务转移、供能与储能联合优化；实际任务可调范围和取得柔性的成本是进一步研究的重要条件。
- [Carbon Explorer作者全文](https://www-cs.stanford.edu/~fiodar/pubs/CarbonExplorer.pdf)。已比较储能、任务调度和额外服务器，说明延期与补做容量限制；连续多日供给不足时调度可能无法完成严格覆盖。
- [Lyu与Li：Do We Still Need Demand Flexibility as Batteries Become Cheaper? A Levelized Cost Perspective，2026年预印本](https://arxiv.org/html/2608.07348v1)。讨论不同时间尺度和容量状态下的成本比较；数据中心延期与服务质量成本未完整纳入，其排序不能直接代替本研究的服务约束与严格CFE计算。
