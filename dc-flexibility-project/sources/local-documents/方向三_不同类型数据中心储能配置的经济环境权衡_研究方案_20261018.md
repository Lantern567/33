# 不同类型数据中心储能配置的经济—环境权衡与优化重点

研究方向三｜研究方案｜2026年10月18日

## 一、科学问题与研究定位

### 核心科学问题

**不同类型数据中心的业务与用能特征，如何决定储能配置的经济—环境权衡及其优化重点？**

研究需要回答：不同类型的数据中心配置储能时，哪些条件决定其更需要较大的输出功率、较长的持续时间、较高的充放电效率、较强的循环能力，或者能够跨代延续的使用期限？这些配置重点如何影响降低成本和减少排放的潜力，两项目标何时一致、何时需要权衡？

“优化重点”具体表现为储能技术、功率、电量、运行时序及投资时间的选择。不同业务类型的侧重点由实际负荷、服务约束和分析结果确定，不预先规定AI训练、推理或通用业务适合某一种技术。

### 经济与环境目标

经济效果以共同评价期内的折现净成本衡量，涵盖电费、储能投资、维护、增补更换、退役与残值。环境效果以**全生命周期温室气体排放**为主要指标，涵盖运行用电变化及新增储能和附属设备的制造、更换与处置排放。

分别识别成本最低、排放最低的配置，再给出两者之间的有效折中范围，回答“达到不同减排要求需要多少成本，以及储能配置如何改变”。不预设所有设施都存在同时实现两项目标极值的单一方案。

### 四个子问题

1. **类型差异：**不同业务类型的负荷形态和服务约束，如何影响储能可提供的削峰、用电时段调整与排放改善空间？
2. **效益与配置：**各类设施的成本最低、排放最低及折中配置有何不同？哪些技术、功率、电量和运行时序能够同时降本减排，哪些选择存在冲突？
3. **差异机制：**负荷与备用约束、电价与排放的时间关系、储能效率与制造排放，分别如何形成这些差异？相同业务在不同地区是否需要改变配置重点？
4. **生命周期变化：**GPU和服务器更新、模型效率提高、需求与电网变化，是否改变上述规律？哪些配置能够持续产生收益，哪些配置可能出现闲置、回收困难或累计增排？

### 研究贡献

已有研究分别讨论了数据中心储能的电费与衰减优化、生命周期负荷增长，也已有数据中心光伏与储能的成本—碳足迹配置研究，纳入设备生命周期排放和地区差异。[Shi等，2016](https://doi.org/10.1145/2934328.2934346)；[Zhang等，2025，机构记录与摘要](https://ira.lib.polyu.edu.hk/handle/10397/110795)；[Figini与Paolone，2025正式发表版](https://doi.org/10.1016/j.segan.2025.101920)，[作者预印本全文](https://arxiv.org/html/2412.13853v1)

本研究拟建立的贡献是：**在共同服务与可靠性要求下，识别业务类型通过哪些机制改变储能经济收益与环境收益的一致性，并解释这些关系如何随设备更新、需求和地区变化，形成不同的配置重点。**全生命周期提供完整评价边界，硬件与软件更新解释规律的变化，地域条件用于检验适用范围。

## 二、业务分类与拟识别的配置重点

### 按实际业务划分数据中心

AI算力中心纳入数据中心的业务分类。设施可以承载多类业务，按组成分析；自营、托管、边缘部署及规模作为独立属性。

| 业务类别 | 需要观测的业务及用能特征 | 需要检验的配置重点 |
|---|---|---|
| AI训练 | 训练质量和完成期限、集群利用率、任务持续时间与间隙、设备代际 | 大规模持续用电、任务间隙和更新后的负荷变化，如何影响储能时长、充电机会及利用率 |
| AI推理 | 请求量、响应和质量要求、模型及任务结构、日内峰谷 | 输出功率、响应能力与备用保留，如何影响经济运行和低排放时段充电；在线与离线业务分别核查 |
| 通用云与企业计算 | 未归入其余四类的计算、数据库和企业业务的负荷组成、吞吐及可用性要求 | 多业务叠加和负荷平滑程度，如何改变削峰收益及所需容量 |
| 存储与内容服务 | 存储量、访问和传输量、冗余、持续基础负荷及更新 | 基础负荷、访问波动与经营持续性，如何影响储能循环、效率及长期收益 |
| 非AI科学计算与高性能批处理 | 作业规模、资源占用、完成期限、排队与利用率 | 作业形成的负荷形态和运行约束，如何改变储能运行窗口及技术需求 |

表中均为待检验关系。训练任务不自动具有任意中断能力，在线服务也不自动具有相同备用要求。各类服务采用对应质量、吞吐、时延或完成期限指标。

分类保证业务不重复计入；云平台内的AI等业务归入相应类别。跨类组成以同一统计时段的IT用电份额表示，各类有效服务量单独记录；无法实测的分摊标明估计依据。只有地点和硬件信息的设施保留类型不确定性。

### 需要识别的四组机制

| 机制 | 解释什么 | 需要形成的证据 |
|---|---|---|
| 负荷形态 | 峰值持续时间、出现频率和充电窗口如何决定功率、电量与循环需求 | 分类型负荷记录及控制规模、地区后的比较 |
| 服务与保障约束 | 任务要求和应急储备如何限制储能可用能力 | 满足同等服务和可靠性后的实际可调度空间 |
| 电价与排放的时间关系 | 降低电费的充放电时序是否也降低排放 | 同一地区、同一时间轴的电价与排放数据及运行对照 |
| 利用强度和收益持续性 | 运行收益能否覆盖投资及制造、更换排放，更新之后能否继续利用 | 多年设备和业务路径、运行次数、经济回收与碳回收情况 |

硬件效率提高可能减少单位服务用电，也可能被新增业务量和质量要求抵消。模型小型化、应用结构与业务增长分别建模，不由模型参数量直接推断设施总负荷。[IEA，Key Questions on Energy and AI](https://www.iea.org/reports/key-questions-on-energy-and-ai/executive-summary)

## 三、方案、情景与共同评价边界

### 储能和购电方案

| 方案 | 主要选择 | 比较用途 |
|---|---|---|
| 无新增储能 | 保留既有应急设施，在当地规则内优化购电与合同 | 建立各目标下的可行参照，识别合同优化本身的效果 |
| 磷酸铁锂 | 选择功率、电量、投运时间和运行时序，允许零新增容量 | 识别该技术在各业务类型中的经济与环境边界 |
| 全钒液流 | 在当地可行的场地、并网及采购条件下选择配置和运行 | 检验持续时间、效率、寿命和设备排放如何影响相对优势 |
| 组合配置 | 允许两种技术共同使用，也允许退化为单一技术或零新增容量 | 衡量共同承担不同任务的额外价值，核实是否确有组合需求 |

当前购电合同下的无新增储能成本可以作为历史参照。正式比较中，各方案在每一评价目标下共享可执行的采购权限、既有供能条件和市场资格；另以固定合同对照分离储能本身的作用，避免把合同更换的全部效果归于储能。未达到给定减排要求的方案单列为不可行。

“同时降本减排”、净排放变化、单位减排成本及碳回收时间，统一相对同一设施、同一未来情景中成本最低的无新增储能方案计算，该共同参照不随目标切换。相同减排要求或预算下的方案对照另行报告；无新增储能不能满足约束时标记不可行，同时保留上述共同参照。

基本电费中的容量或需量收费，按用户类别和合同的实际结算方式处理；削减峰值是否减少账单，由收费规则及允许的合同调整决定。其他市场收入仅在具备资格并满足合同与容量约束时计入，同一份储能能力不能重复承诺。

两种技术均允许在可行范围内选择电量与功率之比，不用预设时长决定排序。组合配置计入必要的接入、控制、场地和维护费用，区分共用与专属设备。技术排序结论限定本研究比较的技术范围。

### 三种评价结果与折中范围

在共同服务和可靠性要求下，分别计算成本最低与排放最低的配置，并逐步改变排放约束，形成对应的最低成本与配置边界。重点报告：

- 哪些条件允许同时节省成本、减少排放，两类收益能持续多久。
- 成本最低配置与排放最低配置在技术、功率、电量和运行时序上有何差异。
- 进一步减少排放需要增加多少成本，或控制增排需要放弃多少电费收益。
- 无新增储能是否仍然适用，以及组合配置相对单一技术的改善有多大。

环境目标主要采用生命周期温室气体排放，不以一个未经说明的加权分数代替成本与排放。单位减排成本仅在净减排为正时计算；对可行但成本和排放均更高的配置明确识别其劣势。

### 多资产生命周期与未来情景

分别记录设施设计及剩余经营期限、GPU和服务器的经济使用期限、储能日历与循环寿命，并采用共同评价期。设备更新后设施与储能可以继续使用；经济回收期和碳回收时间属于评价结果。

GPU和服务器的折损包括物理故障维护、技术迭代导致的经济性淘汰、转用及残值，不假定性能随设备年龄线性下降。制造排放与购置费用依据实际批次记录。企业披露已显示服务器经济使用年限可能随技术变化调整，但不能据此设定全部GPU的统一寿命。[Amazon 2024年报，正文第41页](https://www.sec.gov/Archives/edgar/data/1018724/000110465925033453/tm254123d4_ars.pdf)

未来情景分别改变有效服务需求、软件效率、硬件更新、业务组成、经营期限、电网排放、电价和储能技术经济条件。采用单因素与共同变化对照，识别各因素作用；比较一次性建设、随设备更新分期配置和延后投资。未来信息完全已知的结果仅作理论参照，各可实施方案采用相同的信息条件。

同一设施、同一未来情景内，各储能方案完成相同服务，使用相同硬件更新路径和正常任务运行规则。核查计算吞吐、存储网络与接电能力；无法承载服务的情景标记不可行，共同需要的扩容列为共同条件和费用。GPU等共同更新的成本及制造排放在设施总账中列示，不重复归于储能的增量贡献。

### 经济与排放核算

经济支出统一价格和折现口径。已记录购置、更换现金流后，不叠加同额会计折旧；充放电后的净电费已经体现套利效果；储能衰减通过可用容量、更换和残值反映，避免重复计算。提前退出分别记录出售、转用、保留或拆除的费用与可实现残值。[PNNL储能成本方法](https://www.pnnl.gov/projects/esgc-cost-performance/lcos-estimates)

环境核算包括新增储能及必要附属设备的制造、运输安装、增补更换、退役回收，以及充放电损耗、自耗和运行时序改变的电力排放。核实生命周期系数是否已含充电用电，避免与运行排放重复计算。物理排放按发生年度累计，不套用财务折现率；经济残值不直接折算为负排放，回收信用采用统一分配规则。

设施碳足迹使用与地点和时间匹配的电力排放数据。**逐时平均排放因子支持碳足迹核算；判断对电力系统造成的净减排，需要时变边际排放或相应调度反事实。**主样本可采用碳足迹评价，在可靠边际数据覆盖的地区检验系统影响，两种结论分别报告。电网长期变化作为情景，不把固定排放信号下的结果直接解释为大规模部署后的系统效果。

储能经济运行存在增加排放的可能，充电时段、损耗和替代电源都会影响结果；生命周期评价还需计入新增设备排放。因此，是否减排由完整比较确定。[Hittinger与Azevedo，2015，摘要](https://pubmed.ncbi.nlm.nih.gov/25629631/)

各年应急保障按关键负荷、衰减后的可用容量、输出功率和响应能力核算；专用备用能力统一保留。已有UPS等设备的共同历史费用和排放不重复计入，额外运行导致的提前更换则计入相应方案。

## 四、文章框架与四幅主图

沿用已有NC返修稿和NCC v27主文的结果组织方式：类型差异与问题特征、效益边界、差异机制与空间表现、未来变化及适用范围。以下标题是研究任务，投稿时依据结果凝练结论性标题。

### Introduction

说明不同业务类型数据中心的用能与服务要求存在需要刻画的差异；储能降低电费和改善环境效果可能涉及不同配置及运行方式；提出分类比较、机制识别和生命周期评价的科学问题。明确环境范围为温室气体排放，设备更新和地区条件用于解释类型规律的适用边界。

### Results 1｜不同类型数据中心的用能特征与储能作用空间

建立实际设施、业务分类和设备批次样本，由运行记录校准日内与多年负荷，刻画峰值、峰宽、充电窗口、关键负荷和可用储能能力。控制规模、地区和利用率后，识别业务类型能够解释的差异，保留同一类型内部变化。

**主图1：**样本地点与类型、代表性负荷和备用约束、各类设施可参与经济运行及排放改善的空间。观测与情景推定分别标记。

### Results 2｜各类设施储能配置的经济—环境效益边界

比较无新增储能、磷酸铁锂、全钒液流及组合配置的成本与排放，展示成本最低、排放最低及折中配置。识别两类收益一致或冲突的条件，回答各类型在功率、持续时间、效率、循环与使用期限上的配置重点。

**主图2：**分类型成本—排放边界，配合技术、MW、MWh及运行时序的变化；展示增加减排要求时配置如何改变。允许出现零新增储能最适合某一目标的结果。

### Results 3｜业务约束、电价与排放如何形成配置差异

在相同地区更换业务条件、在相同业务条件下更换地区条件，分离负荷形态、保障约束、电价与排放时间关系、效率及制造排放的作用。解释不同类型为何形成不同侧重点，以及这种规律在哪些地区成立。

**主图3：**关键机制的对照与阈值、类型—地区比较、真实既有站点的配置及效益地图。地图可按共同减排要求或相同预算条件绘制，注明评价目标；不将不同目标下的“最优”直接混合。

空间范围为既有站点的储能技术、容量、时机和投资分布。样本覆盖不完整时报告样本结果；行业外推需要覆盖率及权重依据。设施重新选址所需的用地、网络和迁移条件不属于本研究核心范围。

### Results 4｜设备、业务与电网变化下的配置适用性

检验GPU和服务器更新、模型效率、需求和业务组成、电网排放与价格变化是否改变成本—排放关系。比较一次性建设、分期配置和延后投资，报告收益持续性、经济回收、碳回收、闲置和提前退出损失。

**主图4：**需求、效率与电网情景下的配置边界，投资路径及经济和碳回收情况，长期有效与需要调整的配置条件。缺少可靠概率数据时报告情景范围。

### Discussion、Methods与可用性说明

Discussion围绕类型差异的机制、经济与环境目标的一致性、长期配置及经营主体间收益分配展开；讨论可迁移规律和地点、运行及排放数据限制。

Methods包括设施分类、共同服务、负荷校准、多目标配置、生命周期费用与排放、机制对照、空间和未来分析、独立验证。数据与代码可用性说明交代实际可获取内容及保密限制，不声称尚未完成的数据公开。完整参数和敏感性分析列入补充材料。

## 五、数据基础与新增需求

| 数据层 | 关键字段与用途 | 数据基础及缺口 |
|---|---|---|
| 设施与类型 | 地点、状态、运营主体、业务组成、规模、园区/楼栋/集群关系 | 既有数据中心清单结合运营商公告及Epoch AI，核实类型和统计单位，避免重复计数 |
| 实际运行与服务 | 连续15或30分钟负荷、业务量、质量时限、利用率、冷却及辅助能耗、关键负荷与备用 | 需要分类型真实设施记录；至少连续12个月并补足计费追溯窗口，尽量覆盖设备更新前后及独立验证年份 |
| 硬件更新 | GPU、服务器及存储网络批次、功耗性能、维护故障、更新转用、费用与残值 | 厂商参数和设施披露提供部分基础，实际更新路径和交易费用需调查 |
| 电价与合同 | 时间电价、基本电费、合同调整、购电及市场资格、实际账单 | 按地点、用户类别及年份核实；现货价不代替完整零售账单 |
| 时变电力排放 | 与负荷同一地区和时间轴的平均排放、调入电力处理、可获取的边际排放；未来电网路径 | 优先选择排放数据可核查的地区；年平均因子不能单独解释时移效果，缺少边际数据时限制系统减排结论 |
| 储能性能与费用 | 功率、电量、效率、自耗、衰减、更换、场地接入、维护、退役与残值 | PNNL等提供参数起点，当地报价和适用性需核实 |
| 储能生命周期排放 | 电芯或电解液、功率设备及附属设施的制造、运输安装、增补更换与回收边界 | 技术LCA研究或产品环境声明，核对地域、技术、寿命、分配方法及是否含运行电力；液流与锂电分别取证 |
| 计算设施生命周期 | 共同设备更新的费用与制造排放、经营期限和改造 | 总账需记录；各储能方案相同的部分在增量比较中抵消，不重复计功 |
| 未来变化 | 分类型有效服务需求、软件效率、设备代际、经营退出、电网与储能变化 | 公开研究、企业披露和实测趋势限定范围；情景假设显式标记 |

[Epoch AI设施库](https://epoch.ai/data/ai-data-centers)与[字段说明](https://epoch.ai/data/data-centers-documentation/records)可补充大型AI设施的地点、硬件、状态和容量。IT容量和设施总功率容量均不能替代实测负荷，成本估计不能直接作为项目账本。地点与运营数据分别取证。

日本社区或网格电力数据可提供周边背景；设施级方案仍需设施业务、负荷、实际账单及当地排放数据。半小时数据能够支持相应电量和需量分析，更短时的保障与电能质量结论需要对应观测。

[NLR生命周期排放分阶段资料](https://data.nlr.gov/submissions/171)可帮助核对技术排放边界和范围，不能直接用包含运行电力的全周期平均系数重复叠加逐时充电排放。具体储能仍需取得技术与项目条件匹配的制造、更换和回收资料。

本研究新增的关键数据是：**分类型设施的实际运行记录、与负荷匹配的时变电力排放、技术匹配的储能生命周期排放。**原有设备更新、当地电价合同和储能报价继续保留。缺少运行校准的设施仅用于明确假设下的条件评估，不把模拟轨迹写成实测。

## 六、待检验结论与验证

拟检验的关系包括：业务特征是否能解释配置重点；低价与低排放时段的关系是否改变降本减排一致性；制造、更换排放和损耗是否改变技术排序；硬件与需求变化是否改变经济和碳回收；相同规律在不同地区能否成立。允许得到类型内部差异较大、环境收益较小、成本与排放目标冲突或无需新增储能的结果。

验证限定本研究边界：用真实负荷和合同复现账单；以独立设施或年份验证负荷；检查服务承载、电量守恒、备用、终端电量、费用及排放重复计算；核对时区、地点、年份和排放因子口径；检验设备更新、经营期限、电网与回收假设的影响。

本方案为研究设计，尚未开展设施级仿真，未形成分类型技术优劣、经济收益或排放改善的数值结论。
