# 方向一 柔性匹配

当前采用[全球网格需求侧柔性收益研究方案](全球网格需求侧柔性收益研究方案_20261023.md)。研究按全球陆地网格设置相同计算服务，结合土地利用、本地风光、制冷、算力及储能成本，逐网格计算需求侧柔性净收益。主分析采用网格内时间调整，跨网格任务转移另设网络实验。

该版本形成研究设计，尚未运行全球网格模型或产生收益结果。
