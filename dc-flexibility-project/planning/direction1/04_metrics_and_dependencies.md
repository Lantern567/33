# 方向一 指标口径、参照关系与待补材料

状态：依据研究方案与已找到的[计算细节](../../sources/local-documents/方向一_CFE约束与柔性收益_计算细节_20261018.md)整理实施约束。此处是方法落地清单，本步没有模型输出。

## 成本与收益的对照关系

令 q 为同一 CFE 要求，F 为同一未来情景，H 为共同评估期，M 为相同经营理念。省略这些下标时，不表示可以跨条件相减。C₀ 是 N 的完整总经济成本；Cₛ、Cᴅ、Cₛᴅ 分别是同一权限配对的供能单侧、需求单侧和联合成本。

| 指标 | 公式/约定 | 必须采用的参照 |
| --- | --- | --- |
| 柔性净收益 | Vg = C₀ − Cg | 相同 q、F、H、M 下的正常运营 N |
| 供能已优化后的需求增量 | Vᴅ∣ₛ = Cₛ − Cₛᴅ | 联合组合对应的供能单侧 SL 或 SM |
| 需求已调节后的供能增量 | Vₛ∣ᴅ = Cᴅ − Cₛᴅ | 联合组合对应的需求单侧 DL/DLT/DLTE |
| 协同量 | Iₛ,ᴅ = Vₛᴅ − Vₛ − Vᴅ = Cₛ + Cᴅ − Cₛᴅ − C₀ | 必须用同一联合组合匹配的两个单侧；不能跨权限档位替换 |
| CFE 要求增加的成本 | ΔC_CFE,g(q) = Cg(q) − Cg(no_extra_CFE) | 计算细节已定义；同一组合与理念的无额外 CFE 目标参照 |
| CFE要求引起的柔性收益变化 | Vg(q) − Vg(no_extra_CFE) | 区分正净收益与CFE要求额外产生的收益；每个目标各用对应N参照 |
| 单位用电量净收益 | Vg / E_ref | E_ref为同批业务按预先固定参考执行策略得到的终端设施用电，全部组合/目标共用；具体参考策略待案例确认；多年用参考电量的折现和 |
| 成本降低比例 | Vg / C₀ × 100% | 主口径包含共同固定成本；另报剔除固定成本的比例须另名；仅在C₀>0时报告 |
| 多年路线净收益 | 同一基年、同一折现规则的参照路线成本减对应路线成本 | 相同阶段目标、终点、未来情景；折现率/基年当前不设假数 |
| 企业参与收益 | 实际增量收入 + 补偿 − 增量现金支出 | 按合同期或投资寿命单独核算；不与包含机会成本的总经济成本混为一项 |

协同量正值表示该对照下互补，负值表示部分替代，零值表示可加；不是单独凭联合成本最低就证明协同。任何参与差额的方案不可行，差额应记为空并给出不可行原因，不能填无穷大、零或罚值当作经济结果。

成本应覆盖供能、储能、控制实施、任务调整和有依据的业务机会成本。固定租金、能源投资、电费、传输费及机会成本需按归属核对，防止重复。运行成本主报统一价格年货币/年；路线主报共同基年的折现成本/净收益。

## CFE 和服务验证的最低口径

令L_st为终端设施小时电量、M_st为该站该小时合格匹配电量（MWh），先限定`0≤M_st≤L_st`。全年目标为逐站`Σ_t M_st≥q Σ_t L_st`；小时下限为逐站逐小时`M_st≥α L_st`。这些约束之外还要检查物理平衡、属性与完整声明边界，不能只算一个平均分数。

- 同时保存预设约束与实际核算值；全年加权得分、每小时下限、严格终点分别命名。原文拟定q与α均采用90%、95%、99%、100%，两组约束分别计算。
- 严格终点逐站检查所有有负荷小时，不能通过均值、总量对冲或显示精度掩盖缺口。
- 零负荷小时不形成匹配比例分母；具体数值容差在自含方法规范审阅后单列，不能暗中放宽目标。
- 清洁电源可发电量、可认领属性、合同可交付量分别记录；储能追踪充电来源和损耗，不能重复认领。
- 同时检查终端设施用电边界与包含储能损耗的完整声明边界；清洁充电损耗不计入终端匹配量，也不扩大允许未匹配额度。各情境使用同一期初状态与期末库存规则，并真正完成积压任务。
- 实际减排与逐小时 CFE 匹配是不同指标，不能只因匹配提高就声称实现某个减排量。
- 任务完成量、质量、真实期限、迁移与暂停资格均需检查；不完成相同服务的结果不可作为有效成本对照。

## 缺口时间结构的预登记

先固定共同参考任务策略、供给组合与属性规则，计算`D_ref=max(0,L_ref−G_ref)`。同一站点连续正参考缺口组成一次事件，数值容差先登记；各方案共用此事件序列。运行后未匹配电量`U=L−M`另表记录，不删除优化后已被填补的参考事件。

拟报告持续时间（小时）、平均/最大功率缺口（MW）、事件电量（MWh）、事件数/年、事件间隔，以及恢复SOC和任务积压所需时间/清洁电量/算力。跨站重合比例为双方同时缺口小时数除以至少一方缺口小时数；无缺口时不定义。多年连续输入未恢复前，不用一周样例推断罕见长缺口频次。

储能持续能力用同工况下放电端可交付且扣除应急保留的电量除以额定或最大可持续放电功率，不通过临时降低功率改变技术分类。上述均为待实施指标，无事件统计或技术排序结果。

## 锁定识别的证据要求

收益下降或未来成本上升本身不能证明锁定。需追踪早期选择形成的持久约束，例如合同退出成本、资产剩余寿命、建设周期、扩建上限，进而说明它怎样导致额外替换、提前退出或达标障碍。未来需求增长和技术变化必须作为共同情景施加，不能给某一运营组合额外不利预测。
