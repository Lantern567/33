## 准入条件与停止点

- [ ] 情境 ID、权限、CFE 口径与方案及计算细节一致；模板字段、数值容差及其他新增实施约定已单独审阅。
- [ ] 已确认同服务、同目标、同信息条件及共同评估期。
- [ ] 任务/设施/能源数据在站点和时间上可对应，并有单位与缺失规则。
- [ ] 正常规程有可执行定义，候选优化权限有设备和合同依据。
- [ ] 成本和收入边界已确认；企业参与收益不混入经济净收益。
- [ ] 运营比较使用共同资产；转型比较的阶段、终点、候选集合及资产承接规则已准备。
- [ ] 所有启用组合通过其输入核验后，才另行生成运行配置；此包中的 JSON 保持 `execution_enabled=false`。

若第 2 天仍缺真实期限、属性归属或正常规程，允许交付完整的缺口报告、可获得样例与字段映射；不能宣称已经证明柔性收益、协同、最优投资或锁定。
