# 首1–2日启动清单

状态：以会议提出的“首步建工作区、准备近期初稿”为依据。会议信息没有明确绝对日期；日程须由团队按实际会议日期确认。

## 第1日：定边界、核来源、分任务

- [ ] 指定项目负责人、数据负责人、两篇论文负责人、代码仓库维护人及反馈时间。
- [ ] 确认研究问题与四情境边界；审阅 `four-scenarios.md` 中标为待确认的问题。
- [ ] 阅读 `../sources/research-report.md`，对候选数据按覆盖、粒度、位置类型、状态、许可、容量字段逐项评估。
- [ ] 建立来源登记：原始链接、获取日期、版本/快照、许可文本、校验值、使用限制和责任人。
- [ ] 不把源报告的记录快照当作实时数据；不将城市质心纳入设施局地暴露分析；先审许可再下载或分享。
- [ ] Applied Energy：收集已发表论文、专题正式通知/模板和现有图表清单。
- [ ] 鸟类风险：收集现稿、模型/数据说明和已有“暴露重合”定义；确认导师要求的实际提交节点。

## 第2日：形成可审核的初稿

- [ ] 将确认后的字段映射到 `data-dictionary-template.csv`，只填已有证据支持的字段。
- [ ] 形成四情境一页参数表：基线、开关、决策变量、约束、成本/环境指标、未定数据。
- [ ] Applied Energy：拟出“标题—摘要—章节—小节/论点”三级框架，并列出要替换/重绘的图表；是否满足重复率要求须用正式规则和检测流程复核。
- [ ] 鸟类风险：按现有框架写早期决策角度的文字提纲/初稿；将撞击概率与不确定性分析作为方法待议，不把代理指标称为实测撞击。
- [ ] 进行一次短同步，记录决定、未决问题、负责人和下个检查日期。

## 本阶段的完成标准

- 项目边界、负责人和下次同步时间已记录；
- 数据候选来源及许可状态有台账，禁止事项可追溯；
- 四情境参数表有可审阅版本，但未知项明确标注；
- 两项论文各有材料清单和下一步草案；
- 没有未经核验的数据、模型结果或投稿合规结论。
