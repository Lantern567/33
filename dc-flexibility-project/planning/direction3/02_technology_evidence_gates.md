# 方向三 技术候选与工程证据门槛

依据：[方向三原稿](../../sources/local-documents/方向三_数据中心无碳供能转型中的最优储能方案_研究方案_20261018.md)。状态：候选列表已整理，站点技术准入均未验证，没有据此填入成本、效率或排放数值。

## 1. 候选不是已具备建设条件

| 候选 | 拟比较的选择 | 最低证据 | 当前处理 |
|---|---|---|---|
| 无新增储能 | 新增容量为零，保留共同应急设施 | 既有UPS/电池资产、可调度权限、保障与更换条件 | 必须保留为参照；待资产资料 |
| 磷酸铁锂 | 功率、电量、投运和增补更换 | 站点适用设备、效率/自耗、日历与循环衰减、响应、场地与安全/接入要求、当地费用和LCA边界 | 待取证，未准入运行 |
| 全钒液流 | 功率与电量分别配置，运行与更新 | 具体路线、电堆/电解液寿命、辅助用能、最低运行条件、场地、费用、回收与LCA证据 | 待取证，未准入运行 |
| 多日储能条件路线 | 电解制氢—储存—燃料电池回发电完整链条 | 站点可实施证据；各环节容量、效率、自耗、寿命、费用、场地、运行及交付限制 | **默认排除；无可核查工程证据不得纳入候选** |
| 组合配置 | 仅在已准入技术中联合选择，允许单一技术或零新增容量 | 共用和专属设备、接入、控制、维护与场地成本；不同资产批次与保障能力 | 待单项准入及共用成本证据 |

储能时长由电量与功率共同决定；不预先规定某项技术一定承担短时、长时或多日任务。不以可再生出力缺口“看起来很长”作为多日路线已具工程可行性的证据。

## 2. 分层准入

| 门槛 | 必须留存的材料 | 不通过时的处理 |
|---|---|---|
| G1 来源可追溯 | 原始报告/产品资料/报价或论文、版本日期、页码或表号、获取与使用权限 | 参数为空，禁止设为“已验证” |
| G2 地区与年份适配 | 地区、币种、价格年、税费及运输安装边界，参数调整依据 | 只能列为候选来源，不能直接移植为本地报价 |
| G3 站点可实施 | 可用场地、接入功率、响应及备用条件、许可/安全边界、建设交付条件 | 不进入该站点的技术集合 |
| G4 技术链完整 | 额定/可用功率和电量、效率口径、自耗、衰减、寿命、更换、约束与期末库存 | 禁止仅用单一“往返效率”掩盖缺失环节 |
| G5 财务与排放边界一致 | 初始/增补/更换/退役成本、残值和LCA阶段，是否含充电用电、回收分配 | 暂停经济/环境比较，避免重复计量 |
| G6 可复核 | 来源标识、取值/换算记录、不确定性、复核人和日期 | 保留“待核查”状态 |

公开技术评估可以用于第一轮字段设计；本地工程准入和生命周期比较不能仅靠公开评估的通用参数通过。PNNL 2022报告与2024核算说明已在本地公开资料包中原样归档，仓库提供来源及校验记录；尚未完成参数提取、地区适配或技术准入。文件接收范围见[接收报告](../../data/metadata/public-seed/intake_report.md)。

## 3. 单项证据登记模板

每一条可采用参数至少应记录以下字段；未提供的数据留空或`null`，禁止填零表示未知。

| 字段 | 示例类型/含义（非真实数据） |
|---|---|
| evidence_id / site_id / technology_id | 内部唯一标识；站点与具体工程路线 |
| parameter_name / value / unit | 参数名、原始取值与原始单位 |
| measurement_basis | 额定/可用、AC/DC、单程/往返、系统/部件边界 |
| source_id / source_locator | 原文来源标识及页码/表号/记录位置 |
| geography / price_year / currency | 地区、价格年份及币种 |
| includes / excludes | 是否包含PCS、安装、场地、并网、维护、充电用电等 |
| conversion_method | 单位、汇率或价格年换算；未换算时明确标识 |
| range_low / range_high / uncertainty_basis | 有依据的区间；无依据不设概率 |
| asset_vintage / service_life_basis | 设备批次和寿命证据 |
| engineering_gate / checked_by / checked_on | 通过/待核查/不适用及复核信息 |

## 4. 启动验收

- 技术集合有站点差异，集合内允许零容量；不把候选列表当作全部可建。
- 共同UPS、专用保障容量、额外运行引起的更换可以单独追溯。
- 多日路线有完整转换链和场地证据后才申请解除排除；没有证据时保留排除状态。
- 价格、寿命、效率、排放与残值都能追到同一版本的证据登记；不同边界或价格年不得直接拼接。
- 阶段更新不删除旧设备成本；更换、提前退出与终值方法贯穿评价期。
