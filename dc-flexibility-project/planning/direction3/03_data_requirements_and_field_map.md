# 方向三 初始数据需求、字段与来源映射

依据：[方向三原稿](../../sources/local-documents/方向三_数据中心无碳供能转型中的最优储能方案_研究方案_20261018.md)。原稿中没有附带真实设施运行、合同、账单或已校准技术参数数据表。以下为待录入规范与候选来源映射，**不表示候选数据库符合研究要求**。仓库已有[数据源核查报告](../../sources/research-report.md)、[NC/NCC资料清单](../../data/metadata/existing-data-inventory.json)及[网盘归档记录](../../data/metadata/baidu-netdisk-archive-20261019.json)；这是可追溯恢复入口，不代表本次已经下载并核验全部数据。公开机器规格、计算任务样例和既有模拟负荷不能替代方向三真实设施级负荷、账单与合同。

## 已有资料如何复用

- NC全年输入含活动代理量和风光容量因子，可在恢复、校验版本后用于时间索引与供给形状核对；活动代理量不能直接视为设施用电，风光曲线不证明可执行合同或无碳属性归属。
- NCC需求资料包含2023—2025年模拟IT负荷，采用固定设施清单和年度规模，未含PUE。须保留模拟标签，不可作为真实设施增长或历史计量记录。
- NCC多年气候快照可用于天气敏感性设计，但需核定SSP与光伏校正版本，现有快照不证明九个最终气候组合齐备。国家池和四小时电池的旧边界不能直接转用为逐站点技术准入与多技术最优结论。
- 恢复后的文件先核对归档校验值、字段、年份、单位、权限与适用边界；未完成恢复或核查时维持“归档索引已取得、研究输入待验证”。具体限制见[既有计算说明](../../data/metadata/existing-computations.md)。

## 1. 数据登记与缺失规则

每个文件登记`source_id、文件名/路径、来源机构、原始链接、版本日期、获取日期、地区、时间范围、时间粒度、时区、许可/保密限制、原始/处理状态、复核状态`。每个观测保留`source_id、原始记录位置、质量标记、缺失原因`，观测、估算、情景假设分别标记。缺失留空或`null`，零仅表示有证据的真实零值。

站点键`site_id`、技术键`technology_id`、资产批次键`asset_id`、合同键`contract_id`必须稳定。所有时间为含时区时间戳，并注明区间起点/终点、夏令时规则和单位；不得凭记录条数推断连续完整。

## 3. 核心字段字典

| 字段 | 类型/单位 | 定义与校验 |
|---|---|---|
| `interval_start` / `interval_end` | ISO时间戳含时区 | 半开区间；严格递增，检查缺口、重复、夏令时与跨年 |
| `interval_energy_kwh` | 非负数/kWh | 原始区间电量；若由平均功率换算，记录乘以实际区间小时数的方法 |
| `average_power_kw` | 非负数/kW | 仅当源数据是区间平均功率时使用；瞬时值不得直接当均值积分 |
| `meter_boundary` | 枚举/说明 | 设施总表或分项；总表已含分项时不可叠加 |
| `service_quantity` / `service_unit` | 数值/文本 | 各方案共同有效服务口径；缺失时标记尚未验证服务等价 |
| `cfe_eligible_energy_kwh` | 非负数/kWh/小时 | 经过地域、交付、归属与重复分配核验后的可用电量；非“地区发电全部可用” |
| `billing_interval_minutes` | 正整数/分钟 | 从规则确定，不能因CFE按小时核算而改成60 |
| `demand_lookback_start` | 日期/时区 | 需量回溯窗口起点；连续12个月不一定满足全部回溯规则 |
| `price_value` / `price_unit` | 数值/币种每单位 | 价格类型、币种、价格年、税费/币值口径齐全，未知不填零 |
| `emission_factor` / `emission_basis` | 数值/kgCO2e每单位；文本 | 平均/边际分开；记录地域、时段、生命周期阶段及是否含用电 |
| `soc_total_kwh` / `soc_clean_kwh` | 非负数/kWh | 两类库存独立记录；清洁库存不高于总库存，可用容量随衰减变化 |
| `asset_vintage` / `remaining_life` | 日期/年或循环 | 阶段继承与更新的依据；日历和循环寿命不可混用 |
| `evidence_status` | 枚举 | `received_unchecked / verified / missing / excluded / assumption` |

## 4. 时间尺度与验证流程

1. 保留原始15/30分钟数据，按设施总表检查计量边界、覆盖期、重复/缺失/停机；不先自动插值填完整。
2. 按真实合同和计费规则重建历史账单；误差及解释单独记录，验收容差由账单精度与规则确定，当前未设定。
3. 使用有时区且能量守恒的小时聚合视图用于CFE；原始计费粒度与小时视图并存，逐年检查小时与原始总电量一致。
4. 合格供给按照小时对齐并核验交付与归属；用空值明确表示未知供给，不把缺测当成零供给或全部清洁。
5. 同步核验储能总SOC、清洁属性SOC、效率、自耗和末端库存，以及费用/排放的共同与增量边界。
6. 独立站点、年份或天气验证集在拿到可用数据后确定，不能把同一数据拟合与复核称为独立验证。

## 5. 优先索取的三包材料

| 优先级 | 可直接发给数据负责人的材料清单 | 最低接收条件 |
|---|---|---|
| P0-运行与账单 | 单站至少12个月原始15/30分钟设施计量、对应账单、实际电价/需量规则、必要回溯数据、服务与备用要求 | 时间/单位/计量点明确，可复核服务与账单 |
| P0-供给与合同 | 同期小时无碳供给、属性归属、可执行合同、采购/交付/接入限制、现有义务 | 能区分真实交付、模拟出力和未核查候选来源 |
| P0-储能全生命周期 | 现有设备批次与寿命、拟建路线/场地、地区报价、性能衰减、更新退役残值、LCA边界 | 关键参数可追溯；无工程证据的多日路线排除 |

进度、未来需求和硬件更新资料随后补齐。P0未齐时可继续资料整理，但不得宣称当前最优容量、净减排、严格CFE可达或达标年份。
