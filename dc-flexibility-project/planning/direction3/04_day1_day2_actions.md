## 进入计算的门槛

- [ ] 首个站点、年份、业务服务与可靠性边界确认。
- [ ] 真实15/30分钟设施负荷至少连续12个月，账单回溯与数据缺口处理有依据。
- [ ] 历史账单可复现或偏差逐项解释并获接受。
- [ ] 小时合格无碳供给、属性归属、采购及交付条件可追溯。
- [ ] S-FIXED与S-JOINT分别可配置，共同候选条件一致。
- [ ] 至少参照与拟比较技术具备可核查性能、费用、LCA、备用与工程条件；多日路线缺证据则排除。
- [ ] 总SOC和清洁SOC、损耗、自耗、期末库存守恒规则明确。
- [ ] 评价期、价格年份、折现、残值与更换方法统一；未来阶段承接规则明确。
- [ ] 数据许可、保密范围、模型输入版本与责任人记录完整。

任何门槛未通过，保留配置中的`run_enabled: false`和对应阻塞项。若只具备假设数据，可另行建立明确标注的条件评估，不得写成实际站点验证。
